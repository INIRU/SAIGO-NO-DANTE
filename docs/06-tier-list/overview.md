# 리롤 티어 리스트

> 커뮤니티 투표 기반 인격 티어 리스트

**페이지**: `/tier-list`

---

## 기능 요약

리롤(신규 시작) 시 우선 확보할 인격을 S+/S/A/B/C/F 6단계 티어로 분류하는 커뮤니티 투표형 티어 리스트이다. 관리자가 초기 배치를 설정하고, 사용자 투표로 순위가 반영된다.

## 티어 구조

| 티어 | 의미 | 색상 |
|------|------|------|
| S+ | 필수 확보 | 금색 |
| S | 최상위권 | 붉은색 |
| A | 상위권 | 주황색 |
| B | 중위권 | 노란색 |
| C | 하위권 | 초록색 |
| F | 비추천 | 회색 |

## API

| 엔드포인트 | 메서드 | 설명 |
|------------|--------|------|
| `/api/tier-list` | GET | 티어 리스트 + 투표 현황 조회 |
| `/api/tier-list` | POST | 투표 제출 |
| `/api/admin/tier-list` | GET/PUT | 관리자 티어 배치 관리 |

## 주요 기능

### 커뮤니티 투표

- 로그인 사용자가 인격별 티어를 투표
- 투표 결과 집계로 평균 티어 산출
- 중복 투표 방지 (사용자당 인격당 1표)

### 키워드 필터

- 키워드(상태이상, 효과 등)로 인격 필터링
- `KeywordChip` 컴포넌트를 활용한 필터 UI

### 자판기 7일 잠금

- 신규 시즌 인격(출시 후 7일 이내)은 자판기 잠금 표시
- `diff === 0` 이고 `daysSince < 7`인 인격에 잠금 아이콘 표시
- `IdentityInfoCard`에서 처리

## 관리자 기능

| 페이지 | 기능 |
|--------|------|
| `/admin/tier-list` | 인격 초기 티어 배치 설정 |
| | 티어 간 드래그 앤 드롭 이동 |
| | 투표 리셋 |

## 컴포넌트 구조

```
/tier-list (페이지)
├── 티어 섹션 (S+ ~ F)
│   └── IdentityCard (각 인격)
│       ├── 프레임 + 등급 표시
│       ├── KeywordChip (키워드 뱃지)
│       └── 투표 버튼
├── 키워드 필터 패널
└── 자판기 잠금 표시 (신규 인격)
```
