# 리롤 티어 리스트

> 관리자 편집 기반 리세 인격 티어 리스트

**페이지**: `/tier-list`

---

## 기능 요약

리롤(신규 시작) 시 우선 확보할 인격을 S+/S/A/B/C 5단계 티어로 분류하는 관리자 편집형 티어 리스트이다. 공개 화면은 관리자 페이지에서 저장한 리세 티어 배치를 보여주고, 리세 이륙 자가진단 점수 계산을 제공한다.

## 티어 구조

| 티어 | 의미 | 색상 |
|------|------|------|
| S+ | 개사기 | 붉은색 |
| S | 매우 좋음 | 주황색 |
| A | 좋음 | 금색 |
| B | 적당함 | 초록색 |
| C | 유효 | 청색 |

## API

| 엔드포인트 | 메서드 | 설명 |
|------------|--------|------|
| `/api/tier-list` | GET | 공개 리세 티어 리스트 조회 |
| `/api/admin/tier-list` | GET/PUT | 관리자 리세 티어 배치 조회/저장 |

## 주요 기능

### 리세 이륙 자가진단

- S+ = +3.0점, S = +2.5점, A = +2.0점, B = +1.5점, C = +1.0점
- 같은 수감자의 인격이 여러 개 선택되면 가장 높은 티어의 인격만 계산
- 7.0점 이상은 강한 이륙권, 5.5점 이상은 이륙 권장으로 안내
- 계산 참고 출처: https://gall.dcinside.com/mgallery/board/view/?id=limbuscompany&no=375877

### 자판기 7일 잠금

- 신규 시즌 인격(출시 후 7일 이내)은 자판기 잠금 표시
- `diff === 0` 이고 `daysSince < 7`인 인격에 잠금 아이콘 표시
- `IdentityInfoCard`에서 처리

## 관리자 기능

| 페이지 | 기능 |
|--------|------|
| `/admin/tier-list` | 리세 인격 티어 배치 설정 |
| | 티어 간 드래그 앤 드롭 이동 |

## 컴포넌트 구조

```
/tier-list (페이지)
├── 티어 섹션 (S+ ~ C)
│   └── IdentityCard (각 인격)
│       ├── 프레임 + 등급 표시
│       └── 진단 모드 선택 오버레이
├── 출처/점수 기준 표시
└── 자판기 잠금 표시 (신규 인격)
```
