# 스토리 뷰어

> 게임 스토리를 챕터/에피소드 단위로 열람하는 기능

**페이지**: `/story` 및 하위 경로

---

## 기능 요약

림버스 컴퍼니의 메인 스토리와 프롤로그를 챕터 > 에피소드 계층 구조로 열람할 수 있다. 게임 텍스트 데이터를 기반으로 스토리를 웹에서 읽을 수 있는 형태로 제공한다.

## 라우트 구조

| 경로 | 설명 |
|------|------|
| `/story` | 챕터 목록 (메인 인덱스) |
| `/story/[chapterId]` | 챕터 상세 (에피소드 목록) |
| `/story/[chapterId]/[episodeId]` | 에피소드 상세 (스토리 텍스트) |
| `/story/prologue` | 프롤로그 목록 |
| `/story/prologue/[episodeId]` | 프롤로그 에피소드 상세 |

## 핵심 특징

| 특징 | 설명 |
|------|------|
| 챕터/에피소드 브라우징 | 계층적 네비게이션 (챕터 목록 > 에피소드 목록 > 텍스트) |
| 스토리 텍스트 표시 | 게임 스크립트를 웹 읽기 형태로 렌더링 |
| 프롤로그 분리 | 메인 스토리와 프롤로그를 별도 경로로 분리 |
| 폰트 크기 조절 | `FloatingFontControl` 컴포넌트로 텍스트 크기 조정 |

## 네비게이션 구조

```
/story (챕터 목록)
├── /story/prologue (프롤로그 목록)
│   └── /story/prologue/[episodeId] (프롤로그 에피소드)
├── /story/[chapterId] (챕터 상세)
│   └── /story/[chapterId]/[episodeId] (에피소드 텍스트)
└── ...
```

## 데이터 흐름

```
챕터 목록 페이지
  └── 챕터 카드 클릭
       └── 에피소드 목록 페이지
            └── 에피소드 클릭
                 └── 스토리 텍스트 렌더링
                      └── FloatingFontControl (폰트 크기 조절)
```

## 관련 컴포넌트

| 컴포넌트 | 파일 | 역할 |
|----------|------|------|
| `FloatingFontControl` | `components/ui/FloatingFontControl.tsx` | 플로팅 폰트 크기 조절 버튼 |
