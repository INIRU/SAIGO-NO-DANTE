# 제품 요구사항 정의서 (PRD)

## 비전

림버스 컴퍼니의 게임 데이터를 한 곳에서 조회하고, 거울 던전 전략을 세울 수 있는 웹 애플리케이션을 제공한다. 인게임 데이터를 정확하게 반영하며, 유저가 편성과 전략을 미리 시뮬레이션할 수 있는 도구를 갖춘다.

## 대상 사용자

- **림버스 컴퍼니 플레이어** — 인격/E.G.O 스펙을 빠르게 확인하고 싶은 유저
- **거울 던전 공략 유저** — E.G.O 기프트 조합과 편성을 미리 짜고 싶은 유저
- **커뮤니티 유저** — 본인의 덱을 공유하거나 다른 유저의 덱을 참고하고 싶은 유저
- **신규/복귀 유저** — 리롤 티어 리스트와 뽑기 시뮬레이터로 시작 방향을 잡고 싶은 유저

## 핵심 기능

### 1. 죄수/인격/E.G.O 데이터 조회

| 항목 | 설명 |
|------|------|
| 경로 | `/sinners`, `/sinners/[slug]`, `/sinners/[slug]/identities/[id]`, `/sinners/[slug]/ego/[egoId]` |
| 기능 | 12명 죄수 그리드, 죄수별 인격 + E.G.O 목록, 인격 상세 (스킬/패시브/스탯), E.G.O 상세 |
| 데이터 | `sinners`, `identities`, `skills`, `passives`, `ego`, `ego_skills` 테이블 |

- 인격 상세: 업타이 3/4 스킬 수치, 코인 효과, 공격 레벨 보정, 저항, 패닉 정보
- E.G.O 상세: 각성/침식 스킬, 7죄 저항, 코스트, 전용 키워드
- 정신력 조건: `identity_sanity_conditions` + `mental_condition_templates`로 정신력 증감 표시

### 2. 거울 던전 E.G.O 기프트 백과사전

| 항목 | 설명 |
|------|------|
| 경로 | `/mirror-dungeon` |
| 기능 | 408개 E.G.O 기프트 열람, 키워드/등급 필터, 레시피 조회, 테마팩 정보 |
| 데이터 | `ego_gifts`, `ego_gift_recipes`, `ego_gift_themes`, `keyword_meta` |

- 기프트 활성화 조건: 키워드/다중 키워드/소속/스킬 기반 조건 표시
- 테마팩: 테마별 소속 기프트, 전용 기프트, 보스 이미지, 난이도별 층 정보
- 레시피: 기프트 합성 재료와 결과물 연결

### 3. 거울 던전 플래너

| 항목 | 설명 |
|------|------|
| 기능 | 인격 편성 + E.G.O 기프트 시뮬레이션, 키워드 차트, 활성화 조건 체크 |
| 특징 | 편성→실행 전환 (localStorage 기반 상태 보존), 기프트 인벤토리 관리 |

- 기프트 프리픽스: `final_`, `observe_`, `start_` 구분
- 키워드 차트(KeywordChart): 편성 인격의 키워드 분포 시각화
- PlannerGiftModal: 기프트 선택/강화/제거 UI

### 4. 덱 빌더

| 항목 | 설명 |
|------|------|
| 경로 | `/decks`, `/decks/new`, `/decks/[id]`, `/decks/[id]/edit` |
| 기능 | 덱 생성/편집/조회, 인격 선택, 활성 E.G.O 기프트 패널, 투표/북마크/댓글 |
| 데이터 | `decks`, `deck_identities`, `deck_votes`, `deck_comments` |

- 커뮤니티 공유: 덱 목록 보드, 투표 토글, 북마크, 대댓글 지원
- 노트 태그: NoteChips + NoteAutocomplete로 덱에 태그 부착

### 5. 키워드 사전

| 항목 | 설명 |
|------|------|
| 경로 | `/mirror-dungeon` (키워드 필터), `api/keyword-meta` |
| 기능 | 키워드 이름/설명/최대 중첩/아이콘/죄 친화도 조회 |
| 데이터 | `keyword_meta` 테이블 |

- KeywordChip 컴포넌트: 아이콘 + 이름, 자동 색상
- KeywordTooltip: 호버 시 키워드 상세 설명

### 6. 리롤 티어 리스트

| 항목 | 설명 |
|------|------|
| 경로 | `/tier-list` |
| 기능 | S+/S/A/B/C/F 등급 표시, 커뮤니티 투표 |
| 데이터 | `api/tier-list` (GET/POST) |

- 자판기 7일 잠금: 신규 시즌 인격 (diff===0)은 `daysSince < 7` 체크
- 관리자 편집: `/admin/tier-list`에서 등급 수동 조정

### 7. 뽑기 시뮬레이터

| 항목 | 설명 |

| 기능 | 림버스 컴퍼니 뽑기 시스템 시뮬레이션 |

### 8. 랜덤 편성 (슬롯머신)

| 항목 | 설명 |
|------|------|
| 경로 | `/random` |
| 기능 | 12릴 슬롯머신 UI, 키워드 필터, 컬렉션 연동 |
| 컴포넌트 | `RandomClient`, `OptionPanel`, `KeywordChips`, `SlotMachine`, `SlotReel` |

## 비기능 요구사항

| 항목 | 기준 |
|------|------|
| 성능 | Core Web Vitals 준수, GSAP 동적 import (SSR 방지) |
| 반응형 | 모바일/태블릿/데스크탑 대응 |
| 접근성 | ESC로 모달 닫기, 키보드 네비게이션 |
| SEO | 정적 메타데이터 + `generateMetadata` |
| 모니터링 | Sentry 에러 트래킹, Vercel Analytics |
| 다크 테마 | 기본 다크 테마 (밝은 테마 없음) |
| 사이징 | 사용자 폰트 조절과 반응형 UI 우선. `rem`/design token을 기본으로 하고, `px`는 정밀 픽셀 표현·측정·외부 API 제약에 허용 |
