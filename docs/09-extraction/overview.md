# 뽑기 시뮬레이터

> 게임 내 확률을 기반으로 한 뽑기(가챠) 시뮬레이션

**페이지**: `/extraction`

---

## 기능 요약

림버스 컴퍼니의 추출(뽑기) 시스템을 시뮬레이션한다. 실제 게임 내 확률 테이블을 기반으로 인격/E.G.O 뽑기를 가상으로 체험할 수 있다.

## 핵심 특징

| 특징 | 설명 |
|------|------|
| 실제 확률 기반 | 게임 공식 확률 테이블을 그대로 적용 |
| 뽑기 시뮬레이션 | 단일/10연차 뽑기 시뮬레이션 |
| 확률 표시 | 등급별 출현 확률을 명시적으로 표시 |
| 통계 누적 | 총 뽑기 횟수, 등급별 획득 수 등 통계 제공 |

## 확률 시스템

### 등급별 확률

게임 내 공식 확률을 기반으로 시뮬레이션한다:

| 등급 | 확률 |
|------|------|
| 3성 (SSR) | 기본 확률 |
| 2성 (SR) | 기본 확률 |
| 1성 (R) | 나머지 |

> 실제 확률 수치는 게임 데이터에서 동기화되며, 업데이트에 따라 변경될 수 있다.

### 천장 시스템

- 게임 내 천장(pity) 시스템을 반영
- 일정 횟수 이상 뽑기 시 보장 등급 적용

## 페이지 흐름

```
뽑기 유형 선택 (단일 / 10연차)
  └── 뽑기 실행
       └── 확률 계산 (가중치 랜덤)
            └── 결과 표시 (인격/E.G.O 카드 애니메이션)
                 └── 통계 업데이트 (누적 횟수, 등급 분포)
```

## 특이사항

- 클라이언트 사이드에서만 동작 (서버 API 호출 없음)
- 확률 계산은 `Math.random()` 기반 가중치 랜덤
- 결과는 세션 내에서만 유지 (새로고침 시 초기화)
