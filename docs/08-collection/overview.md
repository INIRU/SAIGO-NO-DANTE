# 컬렉션 체크리스트

> 보유 인격/E.G.O를 체크하고 URL로 공유하는 기능

**페이지**: `/collection`

---

## 기능 요약

사용자가 보유한 인격과 E.G.O를 체크리스트 형태로 관리한다. 체크 상태를 URL 파라미터에 인코딩하여 로그인 없이도 링크 공유가 가능하다. 랜덤 편성의 "컬렉션 전용 모드"와 연동된다.

## 핵심 특징

| 특징 | 설명 |
|------|------|
| 로그인 불필요 | URL 기반 상태 저장 -- 계정 없이 사용 가능 |
| URL 공유 | 체크 상태가 URL 파라미터에 인코딩됨 |
| 인격/E.G.O 분리 | 탭으로 인격 체크리스트와 E.G.O 체크리스트 전환 |
| 랜덤 편성 연동 | 컬렉션 데이터를 랜덤 편성의 필터로 활용 |

## API

| 엔드포인트 | 메서드 | 설명 |
|------------|--------|------|
| `/api/collection` | GET | 컬렉션 상태 조회 |
| `/api/collection` | POST | 컬렉션 상태 저장 |

## 상태 관리

### URL 인코딩 방식

```
/collection?ids=인코딩된_상태

상태 구조:
- 인격 ID 목록 (체크된 인격)
- E.G.O ID 목록 (체크된 E.G.O)
- URL 파라미터로 직렬화 → 공유 링크 생성
```

### 데이터 흐름

```
체크박스 토글
  └── 상태 업데이트 (클라이언트)
       ├── URL 파라미터 동기화 (nuqs)
       └── /api/collection POST (로그인 시 서버 저장)

링크 공유
  └── URL 파라미터에서 상태 복원
       └── 체크리스트 렌더링
```

## 랜덤 편성 연동

1. `/collection`에서 보유 인격/E.G.O 체크
2. `/random`에서 "컬렉션 전용 모드" ON
3. 체크된 인격/E.G.O만 슬롯머신 후보에 포함
4. 컬렉션 상태는 URL 파라미터로 전달

## 관련 컴포넌트

| 컴포넌트 | 파일 | 역할 |
|----------|------|------|
| `CollectionSection` | `components/mypage/CollectionSection.tsx` | 마이페이지 내 컬렉션 섹션 |

## 마이페이지 연동

- `/mypage`에서도 컬렉션 섹션을 표시
- 로그인 사용자는 서버에 컬렉션 상태가 저장됨
- 비로그인 사용자는 URL 파라미터로만 상태 유지
