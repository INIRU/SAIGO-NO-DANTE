# Assist scene models

Runtime files for the Assist Mode scene worker (`lib/vision/scene-worker.ts`), served from `/models/assist-scene/`.

| File | What it is | Source |
|---|---|---|
| `scene.onnx` | Screen-state classifier (15 labels in `labels.json`, input described in `metadata.json`) | torchvision MobileNetV3-small with ImageNet weights (`MobileNet_V3_Small_Weights.DEFAULT`, BSD-3-Clause), fine-tuned by `scripts/vision/train_scene.py` (last feature blocks and head, class-balanced, black UI theme simulated) on 1,278 reviewed frames from five of the maintainer's own recordings (2026-09-21 to 09-25, brown and black UI themes). The training frames are not distributed. Held-out accuracy 163/170 (the previous model 149/170; black UI frames 30/30 vs 23/30). |
| `visual-encoder.onnx` | 576-dimension image encoder | The same torchvision MobileNetV3-small ImageNet weights, exported unchanged by `scripts/vision/build_embedding_index.py` |
| `embedding-index.json` | Encoder vectors of the site's own E.G.O gift and event artwork | `scripts/vision/build_embedding_index.py` |
| `icon-classifier.onnx` | Gift-icon classifier for fusion material slots (449 classes in `icon-labels.json`: every catalog gift, the five vestiges as `9991`, and `blank`; input 96×96 RGB crops of 1.3× the slot region, ImageNet normalization, logits out) | torchvision MobileNetV3-small with ImageNet weights, trained by `scripts/vision/train_icons.py` (12 epochs × 48,000 synthetic slots) on the site's catalog icons, grade numerals (`public/assets/ego-stages`) and keyword icons pasted into 1,568 empty-slot crops, with fading, small captures, JPEG and cursor augmentation. Empty slots and the 887 labelled evaluation crops come from the maintainer's recordings and from recognition samples users sent under the Assist improvement opt-in (`scripts/vision/build_icon_dataset.py`); they are not distributed. 887/887 labelled real slots correct (sha256 `4cddb9e060deba4b…`). |

Generated by `npm run build:assist-worker` (not committed): `scene-worker.js` and the onnxruntime-web (MIT) runtime files
`ort-wasm-simd-threaded.asyncify.{mjs,wasm}` copied from `node_modules`.
